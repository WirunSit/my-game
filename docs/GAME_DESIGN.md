## 2. รูปแบบการเล่นหลัก

- ภาพ 2 มิติ มองจากด้านข้าง ผลัดกันเล่นทีละตา ตาละ 20 วินาที (5 วินาทีสุดท้ายมีตัวเลขนับถอยหลังใหญ่กลางจอ + เสียงนาฬิกา)
- **การเล็งยิง:** ปรับมุม 0–90° (กลับด้านได้) แล้วกดค้างเพื่อสะสมแรง 0–100 (ประมาณ 2.2 วินาทีถึงสุด) ถ้าถึง 100 แล้วยังกดอยู่ แถบแรงและเส้นนำทางจะวิ่งกลับลงมาแล้วขึ้นใหม่ไปเรื่อย ๆ จนกว่าจะปล่อยหรือหมดเวลา (หมดเวลาระหว่างชาร์จ = ยิงด้วยแรงตอนนั้น) กระสุนวิ่งตามแรงโน้มถ่วงและแรงลม
- **ลม:** สุ่มทิศและความแรงทุกตา แสดงเป็นลูกศรบนจอ
- **พื้นที่ระเบิดได้:** แรงระเบิดทำให้พื้นเป็นหลุม ถ้าพื้นใต้ตัวละครหายไป ตัวละครจะตกลงมา และถ้าตกขอบจอก็แพ้
- **การเดิน:** ใช้ "สตามินา" เดียวกับสกิล (1 แต้มเดินได้ 3 px, เต็มหลอดเดินได้ 300 px) ดูหัวข้อ 4.4
- **ขนาดจอออกแบบ:** 1280×720 แล้วย่อหรือขยายให้พอดีจอ (Scale FIT)
- **ตัวช่วยผู้เล่นใหม่ (แบบ Boom Z):** ค่าทั้งหมดอยู่ใน `shared/src/assist.ts`
  - **เส้นนำทาง:** จุดประตามเส้นทางจริงของกระสุน (รวมแรงลมแล้ว) ตามแรงที่กำลังสะสม หรือแรงของนัดก่อนตอนยังเล็งอยู่
    ยาว 900 px ที่ Lv1 แล้วสั้นลงเรื่อย ๆ จนเหลือ 120 px (แค่บอกทิศ) ตั้งแต่ Lv20
  - **ลมเบาลง:** ความแรงลมคูณ 0.3 ที่ Lv1 แล้วเพิ่มขึ้นจนเป็นลมเต็มที่ Lv15 (ตัวเลขลมบนจอคือค่าจริงหลังลดแล้ว)
  - โหมด 2 คนบนเครื่องเดียวกันใช้เลเวลของ save ในเครื่องกับทั้งสองคน (ได้ตัวช่วยเท่ากัน) ส่วน PvP ออนไลน์ต้องตัดสินใจในขั้น 5

### การควบคุม
| | คอมพิวเตอร์ | มือถือ |
|---|---|---|
| เดิน | ← → | ปุ่มลูกศรซ้าย/ขวาบนจอ |
| ปรับมุม | ↑ ↓ | ปุ่มขึ้น/ลง หรือลากนิ้วบนวงเล็ง |
| ยิง | กดค้าง Space แล้วปล่อย | กดค้างปุ่ม FIRE แล้วปล่อย |
| สกิล (ดู 4.4) | 1–7 | แตะไอคอนบนแถบสกิล |

## 3. โหมดการเล่น

### 3.1 ด่านบอส (PvE) — โหมดหลักของการเรียน
แต่ละโลกตรงกับหนึ่งหน่วยการเรียน และมี 3 ด่าน: ด่าน 1–2 สู้กับลูกน้องบอส ด่าน 3 สู้กับบอส

| โลก | หน่วยการเรียน (สสวท. ม.1) | บอส | ลูกเล่นของฉาก |
|---|---|---|---|
| 1 | สารบริสุทธิ์ (สถานะ, จุดเดือด/จุดหลอมเหลว, ความหนาแน่น, ธาตุ/สารประกอบ, อะตอม) | **Mixtron** ราชาสารผสม | บอสแยกร่างได้ |
| 2 | หน่วยพื้นฐานของสิ่งมีชีวิต (เซลล์, กล้องจุลทรรศน์, การแพร่, ออสโมซิส) | **Amoebox** อะมีบายักษ์ | บอสดูดน้ำแล้วพองตัว |
| 3 | การดำรงชีวิตของพืช (สังเคราะห์ด้วยแสง, การลำเลียง, การสืบพันธุ์) | **Venomroot** ต้นไม้กินคน | รากโผล่จากพื้น |
| 4 | พลังงานความร้อน (Q=mcΔt, Q=mL, การถ่ายโอนความร้อน, สมดุลความร้อน) | **Magmadon** มังกรลาวา | พื้นลาวาสร้างความเสียหาย |
| 5 | ลมฟ้าอากาศ (ชั้นบรรยากาศ, ความกดอากาศ, ความชื้น, พายุ, ภาวะโลกร้อน) | **Stormlord** เจ้าพายุ | ลมแรงและเปลี่ยนทิศบ่อย |

**ระบบคำถามระหว่างยิงบอส**
1. **บอสชาร์จท่าไม้ตาย:** ทุก 2–3 ตา จะมีคำถามเด้งขึ้นพร้อมเวลา 20 วินาที
   - ตอบถูก → ขัดท่าบอสได้ บอสมึน 1 ตา ได้ดาเมจโบนัส +30% และได้ "ผลึกความรู้"
   - ตอบผิด → บอสปล่อยท่าใส่ แล้วแสดงคำอธิบายเฉลย ข้อนั้นจะกลับมาถามใหม่ภายหลัง
2. **กล่องคำถาม:** มีกล่องวางอยู่ในฉาก ยิงโดนแล้วได้คำถาม ตอบถูกได้ไอเท็ม (ยิงสองนัด, ฟื้นเลือด, โล่, เทเลพอร์ต)
- คำถามดึงจากหน่วยของโลกนั้น ระดับความยากเพิ่มขึ้นตามด่าน
- **ลูกเล่นบอสที่ทำแล้ว (ขั้น 7):** Mixtron แยกร่างเมื่อ HP เหลือครึ่ง (สารผสมแยกได้), Amoebox ดูดน้ำออสโมซิส ฟื้น 150 และตัวใหญ่ขึ้น (สูงสุด 2 ครั้ง),
  Venomroot รากพิษโผล่ตรงที่ผู้เล่นยืนตาก่อน (มีวงแดงเตือน เดินหนีได้), Magmadon ลาวาสูงขึ้นทุก 2 ตาของบอส ยืนต่ำโดน 80, Stormlord ลมแรง ×1.4 และเปลี่ยนทิศกลางตา
- บอสใช้ท่าไม้ตายทุก 3 ตา (ลูกน้องด่านสองทุก 3 ตา), ค่า HP/ความแม่นปรับด้วยตัวจำลอง `tools/balance.ts` (ดู PROGRESS ขั้น 7)
- **สลับลำดับตัวเลือกทุกครั้งที่แสดง** เพื่อไม่ให้นักเรียนจำตำแหน่งคำตอบได้
- ทุกคำตอบส่งเข้าเซิร์ฟเวอร์ เพื่อใช้ทำสถิติในหน้าครู

### 3.2 PvP 1 ต่อ 1 (ออนไลน์)
- คนแรกกด "สร้างห้อง" จะได้รหัส 5 ตัว (ไม่ใช้ตัวที่สับสนง่าย เช่น 0/O, 1/I) ส่งให้เพื่อนกด "เข้าห้อง"
- จำกัดให้เล่นได้เฉพาะนักเรียนในห้องเรียนเดียวกัน (ครูเปิดให้เล่นข้ามห้องได้)
- มีตัวเลือก **Quiz Duel** ให้ตอบคำถามก่อนยิงทุกตา ตอบถูกได้แรงยิง +15% และเกจไม้ตาย +35 (คำตอบถูกบันทึกไว้ให้ครูดูด้วย)
- **ความยุติธรรม:** ใน PvP ทุกอาวุธมีพลังพื้นฐานเท่ากัน ระดับและเลเวลอาวุธมีผลแค่ท่าพิเศษ (เช่น ★3+ ได้กระสุนแตกตัว) กับเอฟเฟกต์ภาพ
  ทุกคนได้สกิลไอเท็มและเกจไม้ตายเท่ากัน (ต้องตัดสินใจในขั้น 5 ว่าจะเปิดท่าพิเศษให้ทุกคนแบบโหมด 2 คน หรือใช้ตาม ★)
- เซิร์ฟเวอร์เป็นผู้คำนวณการยิงทั้งหมดเพื่อกันโกง (ใช้ `resolveShot` ชุดเดียวกับเกม) แล้วส่งเส้นทางกระสุนและผลให้ทั้งสองเครื่องเล่นภาพเหมือนกัน
- ลมใช้ตัวช่วยของผู้เล่นที่เลเวลต่ำกว่า (ทั้งสองคนเจอลมเท่ากัน) ส่วนเส้นนำทางเป็นของใครของมันตามเลเวล
- ท่าพิเศษเปิดให้ทุกคนเหมือนโหมด 2 คน อาวุธใช้พลังพื้นฐาน (ทุกชิ้นสมดุลกันแล้ว)
- ชนะได้ EXP 70 + เหรียญ 50, แพ้ได้ EXP 30 + เหรียญ 20, ถ้าเพื่อนออกกลางเกมเราชนะ, จบแล้วกด "เล่นอีกครั้ง" ได้ถ้าทั้งสองคนกด

## 4. ความก้าวหน้าของผู้เล่น

### 4.1 เลเวลผู้เล่น (Lv1–30)
ได้ค่าประสบการณ์ (EXP) จากการผ่านด่าน, ตอบถูก (ได้มากกว่าการชนะ), และเล่น PvP (ได้ทั้งตอนชนะและตอนแพ้)

### 4.2 อาวุธ
| ระดับ | ชื่อ | เลเวลสูงสุด | ได้จาก |
|---|---|---|---|
| ★1 | ธรรมดา | 10 | อาวุธเริ่มต้น และด่าน 1–2 |
| ★2 | หายาก | 15 | ด่าน 1–3 |
| ★3 | ยอดเยี่ยม | 20 | บอส |
| ★4 | มหากาพย์ | 25 | บอส (โอกาสต่ำ) หรือหลอมจากอาวุธ ★3 ซ้ำกัน 3 ชิ้น |
| ★5 | ตำนาน | 30 | บอสระดับยาก หรือหลอมจากอาวุธ ★4 |

- **อัปเลเวลอาวุธ:** ใช้เหรียญ + **ผลึกความรู้** (ได้จากการตอบถูกเท่านั้น ทำให้การเรียนกลายเป็นการฟาร์มไปด้วย)
- **ค่าพลังอาวุธ:** ดาเมจ, รัศมีระเบิด, น้ำหนักกระสุน (ผลต่อแรงลม), และท่าพิเศษ
- **อาวุธประจำโลก** (โลกละ 3 ชิ้น รวม 15 ชิ้น + อาวุธเริ่มต้น 1 ชิ้น = 16 ชิ้น ตรงกับ sprite sheet 4×4 พอดี)

| โลก | อาวุธ |
|---|---|
| เริ่มต้น | ปืนใหญ่ฝึกหัด (Starter Cannon) |
| 1 สาร | ปืนบีกเกอร์, เครื่องยิงอะตอม, ปืนกลั่น |
| 2 เซลล์ | ปืนกล้องจุลทรรศน์, ระเบิดออสโมซิส, ปืนนิวเคลียส |
| 3 พืช | ปืนใหญ่คลอโรฟิลล์, หนังสติ๊กเมล็ดพันธุ์, ปืนละอองเรณู |
| 4 ความร้อน | ปืนเทอร์โมมิเตอร์, จรวดการพาความร้อน, ปืนไฟลาวา |
| 5 อากาศ | ปืนบารอมิเตอร์, ปืนฟ้าผ่า, ปืนใหญ่ทอร์นาโด |

### 4.3 การแต่งตัว
ตัวละครสร้างจากหลายชั้นวางซ้อนกัน: ตัวละครพื้นฐาน (ชาย/หญิง) + ชุด + หมวก + ของที่ใบหน้า + ของที่หลัง + อาวุธ
| เลเวล | ปลดล็อก |
|---|---|
| 3 | หมวก |
| 5 | ของที่ใบหน้า (แว่น/หน้ากาก) |
| 8 | ชุด |
| 10 | ของที่หลัง (ปีก/เสื้อคลุม) |
| 15+ | ชุดพิเศษจากบอส |

### 4.4 สกิล (ค่าทั้งหมดอยู่ใน `shared/src/skills.ts`)
ระบบแบบ DDTank / BoomZ: **ทุกตาเริ่มด้วยสตามินาเต็ม 100** (ที่เหลือไม่สะสมไปตาหน้า) การเดินและสกิลใช้สตามินาร่วมกัน
จึงต้องเลือกว่าตานี้จะเดิน หรือจะใช้สกิลคู่ไหน เช่น "+1 คู่ +2" หรือ "สามลูก คู่ +2"
- กดปุ่มบนแถบสกิลเหนือแถบแรง หรือกดเลข 1–9, 0 แต่ละปุ่มบอกราคาสตามินาไว้มุมขวาล่าง
- สกิลการยิงจะ "เลือกไว้" และหักสตามินาทันที กดซ้ำเพื่อเอาคืน เส้นนำทางเปลี่ยนตามสกิลที่เลือก
- สกิลทันที (โล่, ฟื้นพลัง, พรางตัว) ใช้แล้วเกิดผลเลย ยิงต่อได้ และใช้คู่กับสกิลอื่นได้ทุกอัน
- สกิลเดียวกันใช้ได้ตาละ 1 ครั้ง ถ้ากดไม่ได้จะขึ้นเหตุผล (สตามินาไม่พอ / ใช้คู่กันไม่ได้ / ...)

**สกิลไอเท็ม**
| ปุ่ม | สกิล | สตามินา | ผล |
|---|---|---|---|
| 1 | ยิงซ้ำ +1 | 40 | ยิงเพิ่มอีก 1 รอบ ด้วยมุมและแรงเดิม |
| 2 | ยิงซ้ำ +2 | 55 | ยิงเพิ่มอีก 2 รอบ |
| 3 | สามลูก | 45 | ยิงกระจาย 3 ลูก (มุม ±5°) ลูกละ 50% |
| 4 | เพิ่มพลัง | 30 | ดาเมจตานี้ ×1.3 |
| 7 | จรวดกระดาษ | 60 | ตกตรงไหนย้ายไปตรงนั้น โดนลม ×1.5 ไม่มีดาเมจ ใช้คู่กับสกิลยิงอื่นไม่ได้ |
| 8 | โล่ | 35 | โดนยิงเจ็บครึ่งเดียว จนถึงตาถัดไปของเรา |
| 9 | ฟื้นพลัง | 60 | +300 ทันที (2 ครั้งต่อเกม) |
| 0 | พรางตัว | 40 | อีกฝั่งมองไม่เห็นเลย (ตัวละคร ป้ายชื่อ และจุดบนแผนที่ย่อหายไป) จนถึงตาถัดไปของเรา หรือจนกว่าจะโดนยิง (ขึ้น "เจอตัวแล้ว!") เราเห็นตัวเองจาง ๆ, บอสเล็งได้แค่ประมาณ (คลาด 180–320 px) (2 ครั้งต่อเกม) |

**ดาเมจเมื่อยิงหลายรอบ** (ทุกรอบเท่ากัน): 1 รอบ 100%, 2 รอบ (+1) รอบละ 70%, 3 รอบ (+2) รอบละ 50%, 4 รอบ (+1 คู่ +2) รอบละ 40%
สามลูกคู่ +2 = 3 รอบ × 3 ลูก ลูกละ 25% (ใช้สตามินาหมดหลอด เดินไม่ได้)

**ใช้คู่กันไม่ได้:** สามลูก / ท่าพิเศษ / ไม้ตาย / จรวดกระดาษ เลือกได้อย่างเดียวต่อนัด, จรวดกระดาษใช้คู่กับสกิลยิงอื่นไม่ได้เลย, ไม้ตายใช้คู่ +1/+2 ไม่ได้ (แต่คู่เพิ่มพลังได้)

**ท่าพิเศษประจำอาวุธ** (ปุ่ม 5, สตามินา 40) อาวุธ ★3 ขึ้นไป ใช้แล้วพัก 1 ตา (โหมด 2 คนและ PvP เปิดให้ทุกคน) ใช้คู่ +1/+2 ได้
| แบบ | อาวุธ | ผล |
|---|---|---|
| ระเบิดใหญ่ | ปืนใหญ่ฝึกหัด, ปืนนิวเคลียส | รัศมี ×1.6 ดาเมจ ×1.15 |
| ติดไฟ | ปืนบีกเกอร์ (กรด), ปืนเทอร์โมมิเตอร์, ปืนไฟลาวา | ศัตรูเสียพลัง 60 ตอนเริ่มตา 2 ตา |
| แตกตัว | เครื่องยิงอะตอม, ปืนละอองเรณู | ถึงจุดสูงสุดแล้วแตกเป็น 3 ลูก ลูกละ 60% |
| กระดอน | ปืนกลั่น, หนังสติ๊กเมล็ดพันธุ์ | กระดอนพื้น 1 ครั้งก่อนระเบิด |
| ไม่โดนลม | ปืนกล้องจุลทรรศน์, ปืนบารอมิเตอร์ | ไม่โดนลมเลย ดาเมจ ×1.1 |
| ดูดพลัง | ระเบิดออสโมซิส, ปืนใหญ่คลอโรฟิลล์ | ได้พลังคืนครึ่งหนึ่งของดาเมจที่ทำได้ |
| จรวด | จรวดการพาความร้อน | พุ่งตรงไม่ตกช่วงแรก (45 สเต็ป) |
| ฟ้าผ่า | ปืนฟ้าผ่า | ฟ้าผ่าลงจุดเดิมซ้ำอีกครั้ง 60% |
| ผลัก | ปืนใหญ่ทอร์นาโด | ผลักศัตรูกระเด็นไปถึง 120 px (บอสตัวใหญ่ขยับน้อยกว่า) |

**ไม้ตาย (ปุ่ม 6, เกจโกรธ/เกจพลังความรู้)** ไม่ใช้สตามินา แต่ต้องเกจเต็ม 100 ก่อน
เกจเพิ่มจาก: ตอบถูก +35, ยิง 1 ตา +10, ยิงโดนในตานั้น +10, โดนยิง +15 (นับครั้งเดียวต่อตา ไม่ว่าจะโดนกี่ลูก)
เต็มแล้วยิงลูกใหญ่ ดาเมจ ×2 รัศมี ×1.5 ไม่โดนลม และเห็นเส้นนำทางเต็มเส้น การตอบคำถามจึงเป็นทางที่เร็วที่สุดในการได้ไม้ตาย

**พลังชีวิตศัตรู** เพิ่มขึ้นราว ×1.4 ตอนเปลี่ยนมาใช้ระบบสตามินา (ผู้เล่นใช้สกิลได้ทุกตาแล้ว) ตรวจด้วย `npx tsx tools/balance.ts 60 --skills`

## 5. ระบบบัญชีและหน้าครู

### นักเรียน
- เข้าระบบด้วย **รหัสห้องเรียน** (เช่น `M1-3-2569`) + **เลขที่** + **PIN 4 หลัก**
- ตั้ง "ชื่อเล่นในเกม" เอง (มีตัวกรองคำไม่สุภาพ) หรือใช้ค่าเริ่มต้นเป็น "นักเรียน #12"
- ไม่เก็บชื่อจริง เลขประจำตัว อีเมล หรือเบอร์โทร
- ใส่ PIN ผิด 8 ครั้งจะล็อก 10 นาที (หรือให้ครูรีเซ็ต PIN), login ค้างไว้ในเครื่องได้ทั้งเทอม, ความคืบหน้าเก็บบนเซิร์ฟเวอร์ (เล่นเครื่องไหนก็ได้)

### ครู (ใช้ชื่อผู้ใช้ + รหัสผ่าน)
- สร้างห้องเรียน กำหนดจำนวนนักเรียน แล้วให้ระบบสุ่ม PIN และพิมพ์ใบรายชื่อ PIN ได้
- รีเซ็ต PIN ให้นักเรียนแต่ละคน
- **สถิติ:** ข้อที่ผิดบ่อยที่สุด, เปอร์เซ็นต์ถูกแยกตามหน่วยและหัวข้อ, ความคืบหน้ารายคน
- **คลังคำถาม:** เพิ่ม/แก้/ปิดคำถาม, นำเข้าไฟล์ CSV, กดยืนยันข้อที่ AI ร่างไว้ (`reviewed: true`)
- เปิด/ปิดโลกตามบทเรียนที่สอนถึง และเปิดให้เล่น PvP กับห้องอื่นได้
- การสมัครบัญชีครูต้องใช้รหัสสมัคร (`TEACHER_SIGNUP_CODE`) ที่ผู้ดูแลตั้งไว้ กันคนนอกสมัคร
- คลังคำถามใช้ร่วมกันทุกห้องเรียน (หน้า `/teacher`)

## 6. เทคโนโลยี

| ส่วน | เครื่องมือ |
|---|---|
| ตัวเกม | Phaser 4 + TypeScript + Vite |
| เซิร์ฟเวอร์ | Node.js + `ws` (WebSocket ห้อง PvP ที่ `/ws`) + REST API (`/api`) — เลือก `ws` แทน Colyseus เพราะเกมผลัดตาไม่ต้องซิงก์สถานะตลอดเวลา และกติกาอยู่ใน `shared/` อยู่แล้ว |
| โค้ดที่ใช้ร่วมกัน | `shared/` เก็บสูตรฟิสิกส์ของกระสุนและข้อมูลอาวุธ ให้ client และ server ใช้ชุดเดียวกัน |
| ฐานข้อมูล | SQLite ในเครื่อง (`node:sqlite`) ตอนพัฒนา / PostgreSQL (Supabase ฟรี) บนเว็บจริงผ่าน `DATABASE_URL` — ไม่เข้าสู่ระบบก็เล่นได้ (เก็บใน localStorage) |
| นำขึ้นเว็บ | `Dockerfile` + `render.yaml` (Render ฟรี) หรือ Google Cloud Run — คู่มือ `docs/DEPLOY.md` |
| ทดสอบ | `npm run dev` เปิด Vite (8080) + เซิร์ฟเวอร์ (8081) พร้อมกัน Vite ส่งต่อ `/ws` และ `/api` ไปเซิร์ฟเวอร์ จึงใช้พอร์ตเดียว (Web Preview ของ Cloud Shell ใช้ได้) |
