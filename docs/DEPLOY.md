# นำ SciBoom! ขึ้นเว็บ (ให้นักเรียนเล่นได้จากทุกที่)

เกมทั้งหมด (ตัวเกม + หน้าครู + ระบบบัญชี + PvP) รันเป็นเซิร์ฟเวอร์เดียว และเก็บข้อมูลในฐานข้อมูล PostgreSQL

| ส่วน | แนะนำ (ฟรี) | หมายเหตุ |
|---|---|---|
| เซิร์ฟเวอร์ | **Render** (render.com) | ใช้ไฟล์ `render.yaml` + `Dockerfile` ในโปรเจคได้เลย |
| ฐานข้อมูล | **Supabase** (supabase.com) | PostgreSQL ฟรี 500 MB เพียงพอสำหรับหลายห้องเรียน |

> **สำคัญ:** ห้อง PvP เก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์ ต้องรัน **1 เครื่อง (instance) เท่านั้น** (ค่าเริ่มต้นของ Render ฟรีเป็น 1 อยู่แล้ว)
> ห้ามใส่รหัสผ่านฐานข้อมูลลงในไฟล์ใน GitHub เด็ดขาด ให้ใส่ในหน้าตั้งค่าของ Render เท่านั้น

---

## ขั้นที่ 1 — สร้างฐานข้อมูลที่ Supabase (ประมาณ 5 นาที)

1. เข้า https://supabase.com กด **Start your project** แล้วล็อกอินด้วย GitHub
2. กด **New project**
   - Name: `sciboom`
   - Database Password: กด **Generate a password** แล้ว **จดเก็บไว้**
   - Region: **Southeast Asia (Singapore)** (ใกล้ไทยที่สุด)
   - กด **Create new project** รอประมาณ 2 นาที
3. กดปุ่ม **Connect** (ด้านบนของหน้าโปรเจค) เลือกแท็บ **Connection string** → แบบ **Session pooler**
   - คัดลอกข้อความที่ขึ้นต้นด้วย `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres`
   - แทนที่ `[YOUR-PASSWORD]` ด้วยรหัสผ่านที่จดไว้ (ไม่ต้องมีวงเล็บ)
   - ข้อความนี้คือ **DATABASE_URL** เก็บไว้ใช้ในขั้นที่ 2

> ใช้แบบ **Session pooler** เพราะ Render เชื่อมต่อแบบ Direct (IPv6) ของ Supabase ไม่ได้
> ตารางต่าง ๆ และคลังคำถาม 85 ข้อจะถูกสร้างให้อัตโนมัติตอนเซิร์ฟเวอร์เริ่มครั้งแรก

## ขั้นที่ 2 — นำเกมขึ้น Render (ประมาณ 10 นาที)

1. ตรวจว่า push โค้ดล่าสุดขึ้น GitHub แล้ว (`git push`)
2. เข้า https://render.com กด **Get Started** แล้วล็อกอินด้วย GitHub (อนุญาตให้ Render เห็น repo `my-game`)
3. กด **New +** → **Blueprint** → เลือก repo **WirunSit/my-game** → กด **Connect**
4. Render จะอ่าน `render.yaml` และถามค่า 2 ค่า:
   - **DATABASE_URL** = ข้อความจากขั้นที่ 1
   - **TEACHER_SIGNUP_CODE** = รหัสที่ครูต้องใส่ตอนสมัคร (ตั้งเองเช่น `sciboom-ร.ร.ของเรา-2569`) — กันคนนอกมาสมัครเป็นครู
5. กด **Apply** แล้วรอ build ประมาณ 5–8 นาที (ดูความคืบหน้าในแท็บ **Logs**)
   - เสร็จแล้วจะเห็นบรรทัด `SciBoom server on http://localhost:8080 (WebSocket /ws, database: postgres)`
6. ที่อยู่เว็บจะเป็นแบบ `https://sciboom-xxxx.onrender.com`
   - เกม: `https://sciboom-xxxx.onrender.com/`
   - หน้าครู: `https://sciboom-xxxx.onrender.com/teacher`
   - ตรวจสถานะ: `https://sciboom-xxxx.onrender.com/api/health` ควรขึ้น `{"ok":true,...,"db":"postgres"}`

> **แผนฟรีของ Render จะ "หลับ" เมื่อไม่มีคนใช้ 15 นาที** คนแรกที่เข้าจะรอประมาณ 1 นาที
> ก่อนเข้าคาบให้ครูเปิดเว็บไว้ก่อน 1–2 นาที (หรืออัปเกรดเป็นแผน Starter ประมาณ 7 ดอลลาร์/เดือน ถ้าต้องการให้ตื่นตลอด)

## ขั้นที่ 3 — เริ่มใช้ในห้องเรียน

1. ครูเปิด `/teacher` → **สมัครบัญชีครู** (ใส่รหัสสมัครจากขั้นที่ 2)
2. **สร้างห้องเรียนใหม่**: ใส่ชื่อห้อง รหัสห้องเรียน (เช่น `M1-3-2569` หรือเว้นว่างให้สุ่ม) และจำนวนนักเรียน
3. กด **พิมพ์ใบ PIN** แล้วตัดแจกนักเรียน (บนใบมีที่อยู่เว็บ รหัสห้องเรียน เลขที่ และ PIN)
4. แท็บ **ตั้งค่า**: เลือกโลกที่สอนถึงแล้ว (เริ่มต้นเปิดโลก 1) และเปิด/ปิดการเล่นกับห้องอื่น
5. เมนู **คลังคำถาม**: อ่านคำถามที่ AI ร่างไว้ ติ๊ก **ตรวจแล้ว** หรือ **ปิดใช้** ข้อที่ไม่เหมาะ
6. นักเรียนเปิดเว็บเกม → **เข้าสู่ระบบ** → ใส่รหัสห้องเรียน เลขที่ PIN → ตั้งชื่อเล่น
7. หลังนักเรียนเล่น แท็บ **สถิติ** จะแสดงข้อที่ผิดบ่อยและเปอร์เซ็นต์ที่ตอบถูกแยกตามหน่วย

## อัปเดตเกมหลังแก้โค้ด

แค่ `git push` ขึ้น GitHub — Render จะ build และนำขึ้นใหม่ให้อัตโนมัติ (ข้อมูลในฐานข้อมูลยังอยู่ครบ)

## สำรองข้อมูล

- Supabase แผนฟรีไม่มีการสำรองอัตโนมัติ ควรเข้า Supabase → **Database** → **Backups** หรือใช้ปุ่ม **ดาวน์โหลด CSV** ในหน้าคลังคำถามเป็นระยะ
- ถ้าโปรเจค Supabase แผนฟรีไม่มีคนใช้ 7 วัน จะถูกหยุดชั่วคราว (กด Restore ได้ในหน้า Supabase) — ช่วงปิดเทอมควรเข้าไปเปิดดูบ้าง

## ทางเลือก: Google Cloud Run

ใช้ได้ถ้ามีบัญชี Google Cloud (ต้องผูกบัตร แต่มีโควต้าฟรีต่อเดือน) รันใน Cloud Shell ที่โฟลเดอร์โปรเจค:

```bash
gcloud run deploy sciboom --source . --region asia-southeast1 --allow-unauthenticated --max-instances 1 --session-affinity --timeout 3600 --set-env-vars "DATABASE_URL=ใส่ข้อความจาก Supabase,TEACHER_SIGNUP_CODE=ตั้งรหัสเอง"
```

- `--max-instances 1` จำเป็น (ห้อง PvP อยู่ในเครื่องเดียว), `--timeout 3600` ให้การเชื่อมต่อ PvP อยู่ได้ 1 ชั่วโมง

## ทดสอบแบบเว็บจริงบนเครื่องตัวเอง

```bash
npm run build
npm start
```

แล้วเปิด http://localhost:8081 (ไม่ใส่ `DATABASE_URL` จะเก็บข้อมูลในไฟล์ `server/data/sciboom.db`)

## ค่าที่ตั้งได้ (Environment variables)

| ชื่อ | ใช้ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `PORT` | พอร์ตของเซิร์ฟเวอร์ | 8081 (ใน Docker เป็น 8080) |
| `DATABASE_URL` | ที่อยู่ PostgreSQL | ไม่ตั้ง = ใช้ไฟล์ SQLite (ข้อมูลหายเมื่อ Render รีสตาร์ต — ใช้ทดสอบเท่านั้น) |
| `TEACHER_SIGNUP_CODE` | รหัสสำหรับสมัครบัญชีครู | ไม่ตั้ง = ใครก็สมัครได้ |
